========================================
COPY AND PASTE THESE COMMANDS
IN ADMINISTRATOR POWERSHELL
========================================

# Step 1: Navigate to your project
cd "C:\Users\mayan\Desktop\career calender"

# Step 2: Create the cache directory
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.cache\prisma-python\binaries\5.4.2"

# Step 3: Set permissions (if the above worked, this should too)
$cachePath = "$env:USERPROFILE\.cache\prisma-python"
$acl = Get-Acl $cachePath
$permission = "$env:USERNAME","FullControl","ContainerInherit,ObjectInherit","None","Allow"
$accessRule = New-Object System.Security.AccessControl.FileSystemAccessRule $permission
$acl.SetAccessRule($accessRule)
Set-Acl $cachePath $acl

Write-Host "✅ Done! You can now close this window." -ForegroundColor Green

========================================
WHAT TO DO AFTER (IN NORMAL POWERSHELL)
========================================

1. CLOSE the Administrator PowerShell window

2. Open a NORMAL PowerShell window (just press Windows Key, type PowerShell, press Enter)

3. Run these commands:

   cd "C:\Users\mayan\Desktop\career calender\backend"

   python -m prisma generate --schema=prisma/schema.prisma

4. If Prisma generates successfully, you should see:
